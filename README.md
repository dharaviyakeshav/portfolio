# Keshav Dharaviya — Cinematic 3D Portfolio

## What's changed in this edition
- Reworked the visual system with a cinematic near-black / electric-blue / lime palette, luminous grid, glass HUD labels, and stronger typography.
- Rebuilt the Three.js hero scene with a reflective faceted core, bright wireframe shell, torus-knot orbit, multiple orbital rings, and 1,300 ambient particles that react to pointer movement.
- Added pointer-responsive card depth, stronger project-card hover states, floating portrait, animated gradient headline, and scroll-progress HUD.
- Preserved existing project descriptions, assets, and demo links.
- Responsive styling remains included, with reduced-motion support.

## Run
Open `index.html` in a modern browser with internet access. Three.js and Google Fonts are loaded from CDNs. For best results, use a local development server (VS Code Live Server) rather than opening the file directly.
